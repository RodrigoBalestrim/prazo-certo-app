---

## 🚀 O que o sistema faz

O **Prazo Certo** é um sistema completo de controle de validade de produtos com **estoque inteligente**, **cadastro por IA**, **notificações automáticas** e **gestão de equipes**.

### Funcionalidades principais

| Funcionalidade | Detalhes |
|---------------|----------|
| 📸 **Cadastro por foto com IA** | Tire uma foto do produto → a IA identifica nome, marca, categoria e descrição automaticamente |
| 🏷️ **Leitura de código de barras** | Escaneie e consulte Open Food Facts, UPCItemDB e catálogo compartilhado |
| 🗂️ **Controle de validade** | Notificações push automáticas: 30 dias, 7 dias, 1 dia antes e no vencimento |
| 📊 **Estoque PEPS** | Baixa de estoque respeitando "primeiro a vencer, primeiro a sair" com rastreamento por lote |
| 📉 **Dashboard de perda** | Veja em R$ o prejuízo estimado com produtos vencidos e próximos do vencimento |
| 👥 **Equipes e grupos** | 5 níveis de acesso: owner, admin, manager, stockist, viewer |
| 📄 **Relatório em PDF** | Gere relatórios de validade dos produtos selecionados |
| 🔄 **Sincronização offline-first** | Funciona sem internet e sincroniza quando voltar |
| 🖼️ **Remoção de fundo de fotos** | Fotos profissionais dos produtos com fundo transparente (IA) |
| 📋 **Histórico e auditoria** | Todas as alterações registradas com quem, quando e o que mudou |

## 🛠️ Stack técnica

| Camada | Tecnologia |
|--------|-----------|
| **Mobile** | React Native + Expo (Android + Web) |
| **Web** | React Native Web (mesmo código do app) |
| **Landing Page** | Next.js + Tailwind CSS |
| **Backend** | Supabase (PostgreSQL + Auth + Storage + Edge Functions) |
| **Banco** | PostgreSQL 17 com RLS, RPCs, migrations versionadas |
| **IA** | Google Gemini / OpenAI (análise por foto) |
| **APIs externas** | Open Food Facts, UPCItemDB, GTINHub |
| **Notificações** | Expo Notificações (nativas, sem servidor) |
| **PDF** | Expo Print |
